One of Tungsten's original 0.1.0 features was that it could pack images into spritesheets, this is useful if you want to save some memory by reducing draw calls, and reduce some time uploading your assets.

## How does Tungsten pack spritesheets?

Tungsten packs spritesheets using the MaxRects algorithm, which means it packs everything in the smallest sprite possible, and cuts as much dead space as possible.

The same algorithm is used in TexturePacker, which is an industry-standard tool.

## Using spritesheet packing

You can add the `packable` field in your `tungsten.toml`'s input to specify that you want the assets in that input to be packed into a spritesheet. If you're thinking, no. It must be an image asset, you can't pack audio nor models.

```toml
[inputs.images]
path = "assets/images"
output_path = "src/images.luau"
packable = true
```

This only works with `tungsten.toml`, there is no `packable` property for `.tmeta` (we will get into that soon).

Once you sync, your codegen will return something like this:

```luau title="Packed.luau"
-- This file was automatically @generated by Tungsten.
-- It is not intended for manual editing.

local Packed = {
	abc = {
		a = {
			Image = "rbxassetid://123192329092636",
			ImageRectOffset = Vector2.new(0, 0),
			ImageRectSize = Vector2.new(200, 200),
		},
		b = {
			Image = "rbxassetid://123192329092636",
			ImageRectOffset = Vector2.new(200, 0),
			ImageRectSize = Vector2.new(200, 200),
		},
		c = {
			Image = "rbxassetid://123192329092636",
			ImageRectOffset = Vector2.new(400, 0),
			ImageRectSize = Vector2.new(200, 200),
		},
	},
	de = {
		d = {
			Image = "rbxassetid://123192329092636",
			ImageRectOffset = Vector2.new(600, 0),
			ImageRectSize = Vector2.new(200, 200),
		},
		e = {
			Image = "rbxassetid://123192329092636",
			ImageRectOffset = Vector2.new(800, 0),
			ImageRectSize = Vector2.new(200, 200),
		},
	},
}

return Packed
```

You can then use your assets like this:

```luau
local Assets = game.ReplicatedStorage.Assets

-- Require the module Tungsten generated
local Icons = require(Assets.IconSheet)

local home = script.Parent

-- Apply the sprite properties automatically
home.Image = Icons.home.Image
home.ImageRectOffset = Icons.home.ImageRectOffset
home.ImageRectSize = Icons.home.ImageRectSize
```

## Why pack anyways?

As mentioned in the intro of this page, packing into spritesheets can save you some draw calls as one entire spritesheet that contains all your assets can be loaded at once instead of multiple different assets loaded separately. And you don't have to wait for 2 hours when uploading the entire Lucide library to Roblox (I went through that when I was working on LucideRoblox using Asphalt, it was **hell**).

*(Though this doesn't seem to be the case anymore, apparently packing spritesheets is not much more performant than individual assets and it seems to not work well with eviction, cache and LOD.)*

## More packing features?

Tungsten offers a bit more than only packing using the MaxRects algorithm, more than that! This was brought to you by Acecateer from Wonder Works Studio, from their own Tungsten fork!

### Uniform Cells

Instead of your assets scattered around randomly, you can declare uniform cells to ensure that every sprite has the same cell size.

Right after the packable field (or pretty much anywhere inside the input) you can declare the `uniform_cells` field as true:

```toml
[inputs.images]
path = "assets/images"
output_path = "src/images.luau"
packable = true
uniform_cells = true # Over here!
```

Now, you can also take it further by supplying a custom cell size and a cell fit.

Cell size is basically just how big the cells would be, you can supply just a number which it would use as both the width and height, or supply the individual values in an array!

Cell fit has three options, `contain`, `cover` and `stretch`. If you've messed around with Figma or Roblox's ImageLabel's ScaleType, you probably know what these mean. `contain` is just containing the sprite inside the cell, `cover` is it will cover the sprite's sides if it clips out, and `stretch` will stretch the sprite into the cell size. Pretty self-explanatory, isn't it?

```toml
[inputs.images]
path = "assets/images"
output_path = "src/images.luau"
packable = true
uniform_cells = true
cell_size = 25 # Cell size would be 25x25 pixels
cell_fit = "stretch" # Sprites are going to get a bit stretchy!
```
