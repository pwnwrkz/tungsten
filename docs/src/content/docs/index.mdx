# Features

<CardGrid stagger>
  <Card title="Multi-Asset Syncing" icon="rocket">
    Sync Images, Audio, Models, and Animations simultaneously. Powered by
    Roblox's Open Cloud API for secure, high-speed asset management.
  </Card>
  <Card title="Automatic Spritesheet Packing" icon="random">
    Go beyond Asphalt. Tungsten doesn't just sync assets, it automatically packs
    images into optimized spritesheets on the go.
  </Card>
  <Card title="Native SVG Rasterization" icon="seti:svg">
    High-fidelity SVG to PNG conversion with configurable scale factors.
    No external tools required.
  </Card>
  <Card title="Built-in Image Compression" icon="seti:zip">
    Powered by libcaesium. Optimize JPEG/PNG quality and strip metadata locally
    before upload — your assets never leave your machine.
  </Card>
</CardGrid>
