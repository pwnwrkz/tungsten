Meta files are TOML sidecar files that configure an asset or directory without changing `tungsten.toml`. They can override asset metadata sent to Roblox and set SVG rasterization scale.

## File Naming

Tungsten checks for metadata files in this order:

1. **Asset-specific sidecar**: `<name>.<extension>.tmeta` (for example, `logo.png.tmeta`).
2. **Asset fallback sidecar**: `<name>.tmeta` (for example, `logo.tmeta`).
3. **Directory sidecar**: `<directory>.tmeta`, applied to files in that directory and its nested directories.
4. **Configuration defaults**: Values configured in `tungsten.toml`.

For example, `assets/logo.png.tmeta` is the asset-specific sidecar for `assets/logo.png`.

## Supported Fields

| Field | Type | Description |
| ----- | ---- | ----------- |
| `name` | `string` | Overrides the display name sent to Roblox. For packed assets, a directory's name can be used as the generated spritesheet prefix. |
| `description` | `string` | Overrides the description sent to Roblox. |
| `type` | `string` | Overrides the asset type sent to Roblox. The value `"auto"` derives the type from the file kind. For `.rbxm` and `.rbxmx` files, `"animation"` or `"model"` pins the type without parsing the DOM. This takes precedence over the input-level `type`. |
| `svg_scale` | `number` | Overrides the SVG rasterization scale for this asset or directory. The default is `1.0`; the minimum is `0.01`. |

## Examples

### Asset Sidecar

```toml title="assets/logo.png.tmeta"
name = "Official Project Logo"
description = "The high-resolution logo used for the main menu."
```

### Directory Sidecar

Place a sidecar alongside the directory it configures:

<FileTree>

- assets/
  - icons/
    - shop.png
    - settings.png
  - **icons.tmeta**

</FileTree>

```toml title="assets/icons.tmeta"
name = "UIIcons"
description = "Icons for the user interface."
```

When the input uses `packable = true`, generated spritesheets use the directory name as a prefix, such as `UIIcons_001` and `UIIcons_002`.

### SVG Scale

Set `svg_scale` on a directory to apply it to SVGs in that directory and nested directories. An asset-specific sidecar can override the directory value:

```toml title="assets/icons.tmeta"
svg_scale = 2.0
```

```toml title="assets/icons/special.svg.tmeta"
svg_scale = 4.0
```

:::tip
Use custom names to keep assets and generated spritesheets easier to find in the Roblox Create dashboard.
:::
